# Тестування

Для перевірки не потрібна справжня каса.

1. Зареєструйтеся в [кабінеті Checkbox](https://my.checkbox.ua).
2. Створіть **тестову касу** і касира з PIN-кодом.
3. Візьміть ключ ліцензії каси і PIN касира.

Чеки на тестовій касі не потрапляють у податкову. Їхній фіскальний номер починається з `TEST-`.

## Тести бібліотеки

```sh
git clone https://github.com/tolokacode/checkbox-js.git
cd checkbox-js
npm install
npm test
```

Без ключів запускаються лише тести без мережі. Щоб перевірити все на своїй тестовій касі:

```sh
CHECKBOX_LICENSE_KEY=... CHECKBOX_PIN=... npm test
```

Тести відкривають зміну, створюють продаж, повернення і ланцюжок передоплати.
