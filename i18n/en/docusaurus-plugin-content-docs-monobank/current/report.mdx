# Daily report

<span className="badge badge--secondary">since 0.3.0</span>

**WooCommerce → monobank report** shows all installment operations for the chosen day:

- order and contract number;
- number of payments and amount;
- the bank's commission (percent and UAH);
- the amount the bank paid to the shop.

Totals are at the bottom. **Download CSV** saves the table to a file that opens in Excel or Google Sheets.
