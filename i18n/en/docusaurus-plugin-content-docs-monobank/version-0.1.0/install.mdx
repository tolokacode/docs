# Installation

## From the WordPress directory

The plugin is being reviewed by WordPress.org. Once approved, you'll find it under **Plugins → Add New** by searching for "Toloka for monobank".

## From GitHub

1. Download `toloka-monobank.zip` from the latest [GitHub release](https://github.com/tolokacode/toloka-monobank/releases).
2. In WordPress, open **Plugins → Add New → Upload Plugin**.
3. Choose the zip file, click **Install Now**, then **Activate**.

If the plugin is already installed, WordPress offers to replace it with the new version. Your settings are kept.

:::caution Before you install
Back up your site. If you use another installments plugin, switch it off after setting up Toloka, so customers don't see two identical payment methods.
:::

Next, [set up installments](./installments.mdx).
