# Питання та проблеми

### Чи потрібен офіційний плагін plata by mono?

Лише для оплати карткою і для токена передоплати. Покупка частинами працює без нього.

### Статус замовлення не змінюється

- Перевірте, що сайт доступний ззовні і адресу `https://ваш-сайт/wp-json/toloka/v1/chast` не блокує плагін безпеки чи фаєрвол: на неї банк надсилає сповіщення.
- Перевірте, що працює WP-Cron: плагін перевіряє заявки кожні 5 хвилин.

### Де подивитися, що сталося?

**WooCommerce → Стан → Журнали**, джерело `toloka-chast` (Покупка частинами) або `toloka-prepay` (передоплата). Номери телефонів у журналі приховані.

### Знайшли помилку?

Напишіть у [GitHub Issues](https://github.com/tolokacode/toloka-monobank/issues).
