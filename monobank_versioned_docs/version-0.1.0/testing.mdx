# Тестування

Для перевірки не потрібен договір з банком.

1. У налаштуваннях Покупки частинами оберіть середовище **Пісочниця**.
2. Вкажіть тестові дані:
   - Store ID: `test_store_with_confirm`
   - Секретний ключ: `secret_98765432--123-123`
3. Оформіть замовлення. Результат залежить від **останньої цифри телефону**:

| Остання цифра | Що відбудеться |
|---|---|
| 1 | Заявку схвалено |
| 2 | Банк чекає на клієнта |
| 3 | Перевищено ліміт клієнта |
| 4 | Схвалено, чекає підтвердження магазину |

Для передоплати використайте тестовий токен з кабінету plata by mono.

Журнали запитів: **WooCommerce → Стан → Журнали**, джерела `toloka-chast` і `toloka-prepay`.
