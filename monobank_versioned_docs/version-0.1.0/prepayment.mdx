# Накладений платіж з передоплатою

Toloka розширює стандартний **Накладений платіж** WooCommerce. Плагіни доставки працюють з ним як і раніше.

Відкрийте **WooCommerce → Налаштування → Платежі → Накладений платіж**, блок **Передоплата через plata by mono**.

| Поле | Що вказати |
|---|---|
| Передоплата | **Фіксована сума** в гривнях або **відсоток** від замовлення. |
| Розмір передоплати | `0` — звичайний накладений платіж без передоплати. |
| Токен plata by mono | Залиште порожнім, щоб узяти токен з офіційного плагіна «plata by mono». |

Поки передоплата дорівнює 0, нічого не змінюється. Тому встановлення плагіна саме по собі не впливає на магазин.

## Як це працює

1. Клієнт обирає накладений платіж і переходить на сторінку оплати monobank.
2. Після оплати замовлення переходить у статус **В обробці**.
3. Суму, яку клієнт сплатить при отриманні, видно в замовленні в рядку **«Накладений платіж (ТТН)»**.

Якщо клієнт не сплатив, замовлення лишається в статусі **Очікування оплати**, а на сторінці подяки є кнопка «Сплатити передоплату».
