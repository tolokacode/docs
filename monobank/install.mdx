# Встановлення

## З каталогу WordPress

Плагін зараз проходить перевірку на WordPress.org. Після схвалення його можна буде знайти в **Плагіни → Додати новий** за назвою «Toloka for monobank».

## З GitHub

1. Завантажте `toloka-monobank.zip` з останнього [релізу на GitHub](https://github.com/tolokacode/toloka-monobank/releases).
2. У WordPress відкрийте **Плагіни → Додати новий → Завантажити плагін**.
3. Оберіть zip-файл, натисніть **Встановити**, потім **Активувати**.

Якщо плагін уже встановлено, WordPress запропонує замінити його новою версією. Налаштування збережуться.

:::caution Перед встановленням
Зробіть резервну копію сайту. Якщо у вас є інший плагін Покупки частинами, вимкніть його після налаштування Toloka, щоб клієнти не бачили два однакові способи оплати.
:::

Після встановлення переходьте до [налаштування Покупки частинами](./installments.mdx).
