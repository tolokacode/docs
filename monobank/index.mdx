# Toloka for monobank

Безкоштовний плагін для WooCommerce, який додає те, чого немає в офіційному плагіні «plata by mono»:

- **Покупка частинами monobank.** Клієнт обирає кількість платежів на сторінці оформлення і підтверджує покупку в застосунку monobank.
- **Накладений платіж з онлайн-передоплатою.** Клієнт сплачує фіксовану суму або відсоток онлайн, решту — при отриманні.
- **«4 платежі по ~672 ₴»** під ціною на сторінці товару.

Оплата карткою залишається в офіційному плагіні. Toloka працює поруч із ним.

Плагін повністю безкоштовний. Платної версії немає і не буде.

## Вимоги

| | |
|---|---|
| WordPress | 6.5 або новіший |
| WooCommerce | 8.0 або новіший |
| PHP | 7.4 або новіший |
| Валюта магазину | гривня (UAH) |

Працює з класичною сторінкою оформлення і з блоком Checkout. Мови: українська та англійська.
