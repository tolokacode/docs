# Замовлення

## Статуси

| Спосіб оплати | Статус | Що означає |
|---|---|---|
| Покупка частинами | На утриманні | Клієнт підтверджує в застосунку (до 15 хвилин). Не відправляйте товар. |
| | В обробці | Клієнт підтвердив. Відправляйте замовлення. |
| | Виконано | Встановіть після відправки. Банк підтверджує покупку і перераховує кошти магазину. |
| | Скасовано | До «Виконано» скасовує заявку в банку. Після «Виконано» використовуйте повернення. |
| Накладений платіж | Очікування оплати | Передоплата ще не надійшла. Не відправляйте. |
| | В обробці | Передоплата надійшла. |

Статус оновлюється автоматично: банк надсилає сповіщення, а плагін ще й перевіряє заявки кожні 5 хвилин.

## Блок «Покупка частинами monobank»

<span className="badge badge--secondary">з версії 0.3.0</span>

У замовленні праворуч є блок з даними з банку: статус заявки, кількість платежів, картка клієнта, чи повністю сплачено, куди піде повернення, історія повернень.

## Гарантійний лист

<span className="badge badge--secondary">з версії 0.2.0</span>

У тому ж блоці є посилання:

- **Гарантійний лист (PDF)** — відкривається в браузері;
- **Підписаний файл (.p7s)** — оригінал з електронним підписом банку, для бухгалтерії.

## Повернення

Повернення можливе після статусу **Виконано**. Натисніть **Повернення** в замовленні, як зазвичай у WooCommerce. Плагін сам запитає в банку, чи можна повернути кошти на картку; якщо ні — повернення буде готівкою в магазині.

Якщо товар ще не відправлено, просто **скасуйте** замовлення.
