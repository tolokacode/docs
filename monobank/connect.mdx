# Підключення до monobank

Плагін працює через API банку, тому спочатку магазин має підключитися до monobank.

## Покупка частинами

1. Подайте заявку на підключення магазину до Покупки частинами на [monobank.ua](https://www.monobank.ua/) (розділ для бізнесу).
2. Після підписання договору банк надасть:
   - **Store ID** — ідентифікатор магазину;
   - **секретний ключ** — для підпису запитів.
3. Уточніть у договорі, **яку кількість платежів** вам дозволено (наприклад, 3, 4, 6). Ці самі числа потрібно вказати в налаштуваннях плагіна.

:::tip
Поки договору немає, можна все налаштувати й перевірити в [тестовому режимі](./testing.mdx): для нього договір не потрібен.
:::

## Передоплата (plata by mono)

Для накладеного платежу з передоплатою потрібен інтернет-еквайринг **plata by mono** і його **токен**.

- Якщо у вас уже стоїть офіційний плагін «plata by mono», нічого робити не треба: Toloka бере токен з нього.
- Якщо ні, візьміть токен в особистому кабінеті plata by mono і вставте його в налаштуваннях накладеного платежу.

:::note
Порядок підключення в банку може змінюватися. Якщо щось відрізняється від описаного, напишіть нам у [GitHub](https://github.com/tolokacode/toloka-monobank/issues), і ми оновимо документацію.
:::
