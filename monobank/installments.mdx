# Налаштування Покупки частинами

Відкрийте **WooCommerce → Налаштування → Платежі → Покупка частинами monobank**.

| Поле | Що вказати |
|---|---|
| Увімкнути | Позначте, щоб спосіб оплати з'явився на сторінці оформлення. |
| Назва, Опис | Те, що бачить клієнт. |
| Середовище | **Пісочниця** або **Stage** — для тестування. **Продакшн** — для справжніх замовлень. |
| Store ID, Секретний ключ | Дані з договору з monobank. |
| Кількість платежів | Через кому, від 3 до 25, як у договорі. Наприклад: `3,4,6`. |
| Мінімальна / максимальна сума | Покупка частинами показується лише для замовлень у цих межах. |
| Сторінка товару | Показувати «N платежів по X ₴» під ціною. |

## Як це працює для клієнта

1. Клієнт обирає **Покупку частинами** і кількість платежів.
2. Плагін перевіряє, що номер телефону належить клієнту monobank.
3. Клієнт отримує повідомлення в застосунку monobank і підтверджує покупку протягом 15 хвилин.
4. Замовлення переходить у статус **В обробці** — можна відправляти товар.

:::tip Телефон
Для Покупки частинами потрібен номер, прив'язаний до monobank. У блоці Checkout поле «Телефон» за замовчуванням необов'язкове — зробіть його обов'язковим у редакторі сторінки оформлення.
:::

Що робити із замовленням далі, описано в розділі [Замовлення](./orders.mdx).
